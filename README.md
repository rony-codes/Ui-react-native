## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/telecare-ui.git
```

Install dependencies:

```bash
npm install
```

Start the Expo server:

```bash
npx expo start
```

---

## Dependencies

Install vector icons:

```bash
npx expo install @expo/vector-icons
```
